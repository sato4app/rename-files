## rename-files - ファイル名の一括変更

フォルダを選び、変更方法を指定し、**変更前と変更後を一覧で確認してから**ファイル名を一括変更する
デスクトップアプリです。コマンドライン版で分かりにくかった「対象の指定」と「置換内容の指定」を
画面上で行えるようにしました。

### 起動方法

`rename-files.bat` をダブルクリックします。フォルダをこのバッチにドラッグ＆ドロップすると、
そのフォルダを開いた状態で起動します。

コマンドから起動する場合:

```bash
python rename_files.py
python rename_files.py "C:\data"    # 対象フォルダを指定して起動
```

Python 3.8 以降が必要です。追加のライブラリは不要で、標準の tkinter だけで動作します。

### 使い方

画面は上から順に 3 段階です。

**1. 対象を選ぶ**

| 項目 | 説明 |
| --- | --- |
| フォルダ | 「参照...」で選ぶか、パスを直接入力します |
| ファイル名の条件 | `*.jpg` `IMG_*` のようなワイルドカードで対象を絞り込みます |
| サブフォルダも含める | 下の階層のファイルも対象にします |
| 並び順 | 連番を振るときの順番です。名前順は `file2` が `file10` より前になる自然順です |

**2. 変更方法を指定する**

3 つのタブから選びます。共通の「拡張子は変更しない」をオンにすると、拡張子を除いた部分だけが
変更対象になります。

- **文字列を置換** — ファイル名の中の文字列を別の文字列に置き換えます。置換後を空欄にすると
  その文字列を削除します。大文字と小文字を区別しない指定もできます。
- **連番を付ける** — `001, 002...` の数字、または `A, B, C...` の英字（Z の次は AA）で連番を振ります。
  開始値・増分・桁数・区切り文字を指定でき、付ける位置は次の 4 通りです。
  - 名前の先頭に付ける / 名前の末尾に付ける
  - 名前を連番だけにする
  - 上の「ファイル名の条件」の `*` の部分を置き換える
- **前後に追加・削除** — 先頭・末尾への文字列追加と、先頭・末尾からの文字数削除を行います。
  削除してから追加する順に処理します。

**3. 変更内容を確認する**

入力を変えるたびにプレビューが自動更新されます。変更後の名前と、その行の状態が並びます。

| 状態 | 意味 |
| --- | --- |
| 変更します | チェックが付いた行が実行対象です |
| 変更なし | 変更後の名前が元と同じ（灰色で表示） |
| 赤字のメッセージ | 名前の重複、既存ファイルとの衝突、使えない文字などで変更できません |

チェック欄のクリック（または行を選んでスペースキー）で 1 件ずつ対象から外せます。
「変更があるものだけ表示」をオンにすると、変更なしの行を隠せます。

確認できたら「名前を変更する」を押します。直後であれば「元に戻す」で変更前の名前に戻せます。

### 安全のしくみ

- **実行前に必ず全件をプレビュー表示**し、問題のある行は変更対象から自動的に外します
- **2 段階リネーム** — いったん一時的な名前を経由するため、`A→B` `B→A` のような入れ替えも安全です
- **途中で失敗したら全件を元に戻す** — 中途半端な状態で終わりません
- **元に戻す** — 直前の実行結果を記録しており、1 回分の取り消しができます（アプリを閉じると失われます）
- Windows で使えない文字（`\ / : * ? " < > |`）、末尾の空白・ピリオド、予約語（`CON` `PRN` など）、
  パスの長さを事前に検査します

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `rename_files.py` | 画面（tkinter）とユーザー操作の処理 |
| `rename_core.py` | 対象の収集・変更後の名前の組み立て・検証・実行。画面に依存しない |
| `rename-files.bat` | Windows 用の起動ショートカット |
